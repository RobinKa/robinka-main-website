NetPrints

2019 · from the archive

NetPrints is a visual programming language inspired by Unreal Engine 4’s Blueprints. It compiles into .NET binaries or C# source code, which can be used from any other .NET language, such as C#, or run as standalone programs. Any .NET binaries (.NET Framework, .NET Core and ideally .NET Standard) can be referenced and used: the goal is to support anything that is made in C#.
