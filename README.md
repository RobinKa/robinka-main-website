# warlock.ai

Robin Kahlow's website, served by GitHub Pages as plain static files (`.nojekyll`).

* `index.html`: the home page (latest post, archive, contact); `assets/site.css`: its style.
* `blog/<post>/`: posts, each a self-contained page with its own media.
* `netprints/`, `netprintsunity/`, `dip/`, `projects/`: archived pages at their old URLs; `maxwell/` redirects to cemsim.com.
* `painter/`, `deepimageprior/`, `graph/`, `symplectic/`, `tadiff-frontend/`: web apps (built React apps).
* `feed.xml`: the RSS feed.
